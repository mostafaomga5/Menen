# ورشة تصميم ماكينة M-01

استوديو ويب عربي تفاعلي يساعد على تصور ماكينة تركيب روندلة داخل غطاء، وإدخال القياسات واستكشاف أجزاء الماكينة وتخطيط المحطات في مجسم ثلاثي الأبعاد.

> هذا نموذج تصميم تعليمي، وليس برنامج CAD/CAE صناعيًا معتمدًا، ولا مخطط تصنيع أو توصيل. الأجزاء التي لم تُقَس تظل تمثيلية. لا تشترِ مكونات نهائيًا أو تصنع أجزاء قبل مراجعة الأبعاد والأحمال والسلامة مع مهندس مختص.

## التشغيل محليًا

المتطلبات: Node.js حديث وpnpm (نسخة 11.25 أو متوافقة مع حقل `packageManager`).

```bash
pnpm install
pnpm dev
```

افتح العنوان المحلي الذي يعرضه Vite. لإنتاج ملفات الموقع الثابتة:

```bash
pnpm build
```

ينتج Vite النسخة المبنية في `dist/`، ثم ينسخ `pnpm build` الملفات العامة الجاهزة إلى جذر المستودع (`index.html` و`assets/` وملفات `public/`). لذلك إذا كان GitHub Pages مضبوطًا على الفرع `main` ومجلد `/(root)`، يكفي دفع التحديث ليعرض الموقع المبني بدل HTML المصدر. ملفات الشفرة والمواصفات تبقى في `app/` و`docs/`، ويستبعدها إعداد Pages من الموقع العام. يعمل الموقع دون خادم أو قاعدة بيانات.

## استخدام المحرر المباشر

1. على الهاتف، أدر الشاشة إلى الوضع الأفقي عند الدخول إلى مساحة العمل. زر الاتجاه يطلب قفل الشاشة فقط حيث يسمح المتصفح؛ وقد تحتاج إلى تدوير الهاتف يدويًا.
2. اختر «قالب M-01» لعرض الآلية التعليمية، أو «مشروع فارغ» لتركيب نموذج ميكانيكي جديد من مكتبة الأجزاء.
3. المس/انقر الجزء في المجسم أو في شجرة المكونات لفتحه في لوحة الخصائص. استخدم مقابض التحريك/الدوران/التحجيم، أو عدّل أبعاد X/Y/Z وموقعه وزواياه الرقمية. استخدم سهام الإزاحة مع مقدار المليمترات المكتوب. اختر الجزء وانسخه أو أخفه أو احذفه.
4. أضف عارضة أو لوحًا أو عمودًا أو مجرى أو أسطوانة تمثيلية أو مخزنًا أو عربة انزلاق أو غطاءً/روندلة. اربط الجزأين بمفصل ثابت أو منزلق أو دوراني وحدود رقمية؛ المفاصل المجردة لا تمثل اعتمادًا لمحمل/دليل خطي فعلي.
5. من «الحركة وPLC افتراضي»، شغّل دورة M-01 أو تقدم خطوةً بخطوة. عدّل السرعة العامة وسرعات الدافع والغراء واللسان والفاكيوم والكبس كلًّا على حدة. النسبة الأقل قد توقف الخطوة عند موضع جزئي بدل تجاوزها. يمكن تجربة مخرجات وحساسات افتراضية في الوضع اليدوي/التلقائي؛ لا يوجد اتصال بـ PLC حقيقي.
6. أوقف/أعد الضبط عند ظهور عائق. يعرض البرنامج أسماء الأجزاء التي تداخلت أو رابط التجميع الذي تجاوز حدّه، ويمنع مسار الحركة وفق المصادمات المدعومة. سجل Canvas الحالي بصيغة WebM إن دعمه المتصفح، حتى 30 ثانية؛ التسجيل لا يحوي صوتًا.
7. احفظ محليًا أو صدّر/استورد JSON. إعدادات المستخدم تبقى في المتصفح ولا تُرفع تلقائيًا.

قيم M-01 الابتدائية توضيحية، وكل الأبعاد غير المقاسة تمثيلية. مرجع الحركة المختصر موجود في `docs/index-2-motion-reference.md`، والقيود والمعلومات المطلوب تأكيدها في `docs/limits-and-decisions.md`. هذا المحرر ليس CAD/CAE صناعيًا ولا يحاكي ديناميكا الهواء أو الغراء أو إجهاد اللحام أو التفاوتات؛ راجع الحدود الهندسية قبل التصنيع.

## رفع يدوي إلى GitHub

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع ملفات هذا المجلد باستثناء `node_modules/` و`.git/` وملف إعدادك الخاص.
3. أو من الطرفية:

```bash
git init
git add .
git commit -m "Build M-01 design studio"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

استبدل `USERNAME/REPOSITORY` بمعلومات مستودعك. لا ترفع بيانات حقيقية أو صورًا سرية دون رغبتك.

## نشر اختياري على GitHub Pages

النشر الحالي يستخدم GitHub Pages من الفرع `main` ومجلد `/(root)`، مع رفع الملفات المترجمة التي ينتجها `pnpm build`. قالب بديل للنشر التلقائي عبر GitHub Actions موجود في `docs/deploy-pages-template.yml`؛ عند استخدامه، انسخه إلى `.github/workflows/deploy-pages.yml` من حساب يملك صلاحية إضافة workflows، واختر **GitHub Actions** في **Settings → Pages**. الأصول المبنية نسبية لتعمل تحت مسار المستودع. ملفات المصدر والمواصفة مستبعدة من الموقع العام بواسطة `_config.yml`، وتبقى محفوظة في المستودع الخاص. قياسات التصميم تظل في متصفح المستخدم.

## بنية المشروع

- `app/index.html`: مدخل الموقع وأقسام المحرر والـPLC الافتراضي والسلامة.
- `app/src/main.ts`: حالة المشروع، التفاعل، التخزين المحلي، I/O الافتراضي وتسلسل الدورة.
- `app/src/model/mechanical.ts`: كتالوج الأجزاء، نموذج التجميع، مفاصل القالب وتطبيع JSON.
- `app/src/scene/MechanicalWorkbench.ts`: Three.js، الكاميرا، المقابض، اختيار القطع وتسجيل WebM.
- `app/src/physics/RapierPhysics.ts`: المصادمات المدعومة وفحص حدود المفاصل ومسار الحركة.
- `app/src/simulation/m01-motion.ts`: مسارات دورة M-01 ذات المشغلات والسرعات المستقلة.
- `app/src/model/project.ts` و`app/src/ui/diagrams.ts`: مراجع التعليم القديمة ومخططات الهواء والتحكم.
- `app/src/styles.css` و`app/public/`: التخطيط المتجاوب والأيقونة وملف المسارات.
- `docs/`: مواصفة M-01 وملخص الحركة والحدود الهندسية والجدوى؛ تُستبعد من صفحة GitHub Pages العامة.
- `scripts/publish-root.mjs`: ينسخ الملفات المترجمة إلى جذر Pages.
- `index.html` و`assets/`: ملفات ناتج بناء الموقع العام، وليست المصدر القابل للتحرير.

## بيانات ترفع دقة المجسم

صور واضحة للغطاء والروندلة مع مقياس، أبعاد المنتج والخامات، مساحة العمل، بيانات الضغط والتدفق ولوحات البساتم والصمامات، نوع الغراء وموضعه، أشواط الحركة، ترتيب المحطات، وطريقة إخراج المنتج. رسومات المورد أو ملفات CAD تتيح تمثيلًا أدق للمكونات التجارية.
